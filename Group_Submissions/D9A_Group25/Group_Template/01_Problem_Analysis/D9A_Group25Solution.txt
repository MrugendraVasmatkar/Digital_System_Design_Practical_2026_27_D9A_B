We have been given a circuit block diagram which is a game XP level indicator which takes a 4 bit XP value and classifies it as beginner: 0-3, intermediate: 4-10 and expert: 11-15. It has a Moore FSM with states idle, beginner, intermediate and expert and controlled using START, ACK and RESET.
The problem asks us to modify a game XP level indicator circuit such that upon change in XP level, the previous XP level is displayed on a separate LED while showing the current XP level on the primary LED. The change must generate a HIGH signal. 

The circuit must accept a 4 bit XP value through the input register and classify it correctly for all 16 values, with 0-3 as beginner, 4-10 as intermediate and 11-15 as expert. The current level must be shown on the primary LEDs (LED1, LED2, LED3) and must stay on until ACK is given. The circuit must remember the previously detected level and compare it with the newly detected level every time a new input is loaded using START. If the two levels are different, the FSM must generate a HIGH change signal, and this signal must make the second set of LEDs (LED4, LED5, LED6) glow to show the previous level. The second set must turn off when the next input comes in, and it must glow again only if that input also changes the level. The circuit must support START, ACK and RESET, where RESET clears the stored level and all LEDs.

We assume the circuit starts from idle state so all LEDs are off in the beginning with no previous state to compare with.
inputs: clk, rst, st, ack, xp_sw0, xp_sw1, xp_sw2, xp_sw3
outputs: led1, led2, led3, led4, led5, led6

Constraints: The XP input is limited to 4 bits, so only the values 0 to 15 can be given. The circuit is fully synchronous and works on a single clock, with an active-high reset. The change signal must be generated for one clock cycle only, and it must come from a flip-flop so that it does not glitch when it is used as the clock of the second LED set. The second set of LEDs can show only one previous level at a time. The previous level is stored only after the first input following RESET, so no change can be detected before that. For the FPGA, the buttons need debouncing of about 5 ms and a synchronizer, and the pins and the clock period must be set in an XDC file. The design is built in Logisim, Verilog and Vivado.

Solution: The 4 bit XP value from the switches is loaded into the input register in parallel in serial out when START is pressed. The 4 bit output of this register is given to two places. First, it goes to the XP comparator, which classifies it and gives three lines, beginner, intermediate and expert, to the FSM. These three lines are used by the next-state logic of the FSM to decide which level state it moves to. Second, the same 4-bit output from the input register goes directly to the FSM as the current input, where an internal comparator finds the current level of this input. The FSM then compares this current level with the level stored from the previous input. Because the output depends on both the current state and the current input, the FSM works like a Mealy machine for the change detection, while the primary LEDs still show the current level until ACK is given. If the two levels are different, the FSM generates a HIGH change signal for one clock cycle. This signal acts as the clock of the second LED register, which captures the previous level and makes the matching LED among LED4, LED5 and LED6 glow. When the next input comes in, the second set is cleared, and it glows again only if that input also changes the level. ACK takes the FSM back to IDLE and RESET clears the stored level and all the LEDs.
