Problem Analysis

Problem Statement:
Redesign the Gaming XP Level Decoder (4-bit XP, 0–15) as a Mealy FSM. The level output (BEGINNER / INTERMEDIATE / EXPERT) must be generated immediately from the current state and the current input XP[3:0], not only after the next clock edge. Draw the Mealy state diagram, then implement and verify it in Logisim and Verilog.

Requirements:
XP 0–3 should show BEGINNER, 4–10 INTERMEDIATE and 11–15 EXPERT.
Outputs must depend on both the present state and the input XP[3:0].
START loads the XP value, ACK sends the FSM back to IDLE, and RESET is synchronous and active-high.
The submission needs a state diagram, a Logisim circuit and Verilog code.
A self-checking testbench must test all 16 XP values (0 to 15) and print pass/fail messages.

Assumptions:
All state changes happen on the rising edge of a single clock.
XP stays stable while START is high.
Only one LED is on at a time, and all LEDs are off in IDLE.
XP is always between 0 and 15, so there is no invalid input to handle.
RESET has the highest priority and always brings the FSM back to IDLE.

Inputs and Outputs:
 CLK -> Input -> System clock
 RESET -> Input -> Synchronous reset, active-high
 XP[3:0] -> Input -> 4-bit XP value
 START -> Input -> Starts decoding and samples XP
 ACK -> Input -> Acknowledge, returns the FSM to IDLE
 BEGINNER_LED -> Output -> High for XP 0–3
 INTERMEDIATE_LED -> Output -> High for XP 4–10
 EXPERT_LED -> Output -> High for XP 11–15

Constraints:
XP is only valid from 0 to 15.
The FSM must be Mealy, so outputs change as soon as the input changes.
Only one level LED can be active at any time.
All outputs stay off in IDLE and after RESET.
The testbench must check the expected output against the actual output for every value.

Proposed Solution:
The FSM has four states: IDLE (00), BEGINNER (01), INTERMEDIATE (10) and EXPERT (11).
A range decoder compares XP and finds which range it falls in: ≤3, 4 to 10, or ≥11.
In IDLE, when START = 1, the output is generated right away from the current state and the XP value. The next state is set to the matching level state.
In a level state, the LED stays on until ACK = 1, after which the FSM goes back to IDLE.
RESET forces the FSM to IDLE and turns all LEDs off.
The next-state and output logic are combinational, and only the state register is clocked.
Because the output depends on the input as well as the state, the level shows up without the extra clock delay of the Moore version. This is the main difference between the two.
