2. Assigned Problem Statement
Number/title: [ 9- Password Attempt Monitor ]
Problem summary: [ Password attempt monitor is to be designed where as per the number of attempts the respective led should glow]
Objective: [ Read an attempt value, identify its category, and show that category using a Moore FSM. The circuit must support NOW, WARN, LOCKOUT, and ERROR states. START begins processing, while ACK or RESET returns the FSM to IDLE.]
Inputs and outputs: [ input - CLK, ACK, START, RESET, A3,A2,A1,A1  output- NOW LED, WARN LED, LOCK LED, ERROR LED]

3. Problem Analysis and Proposed Solution
The circuit must divide the input range into four non-overlapping categories: 0–1, 2–4, 5–7, and 8–15. The boundary values 1/2, 4/5, and 7/8 require particular attention so that adjacent categories do not overlap or leave gaps.
Two comparators check the attempt value against the boundaries 2 and 5.
Combinational gates use those results and A3 to select a category:
NOW: attempt value is less than 2.
WARN: attempt value is at least 2 and less than 5.
LOCKOUT: attempt value is at least 5 and at most 7.
ERROR: A3=1, which represents values 8–15.
